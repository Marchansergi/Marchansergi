# Hi, I'm Sergi

IT student from Girona (Catalonia), training in networking and microcomputer systems (SMX). I build side projects to practice what I learn: Linux administration, networks and software development.

## Featured projects

**[Linux Server Manager](https://github.com/Marchansergi/Linux-Server-Manager)** (Python): self-hosted, read-only web dashboard to monitor Linux servers in homelabs and small infrastructures. Session-based login, scrypt password hashing, rate-limited logins and a non-root Docker container.

**[NexusLAN](https://github.com/Marchansergi/NexusLan)** (Python): offline LAN communication tool for schools, labs and offices. Chat, file sharing, PC monitoring and role management with automatic network discovery, no internet, accounts or admin permissions needed.

**[Quart Minecraft Mod](https://github.com/Marchansergi/Mod-Minecraft-Quart)** (Java, Fabric): mod for Minecraft 1.21.1 that recreates my hometown area of Quart (Girona) at real scale, 1 block = 1 meter.

**[Hoy, Daily Check-In](https://github.com/Marchansergi/Daily-Check-in-tool)** (TypeScript, Next.js): minimalist daily journal with markdown notes and tasks you can drag to future days. 100% client-side and offline.

**[Clean Card](https://github.com/Marchansergi/Clean-Creditcard)** (Kotlin, Android): app to design your own card skin and show it full screen when paying with your phone. The payment itself is handled by Google Wallet.

**[Password Manager](https://github.com/Marchansergi/Password-manager)**: simple password manager with setup instructions included.
